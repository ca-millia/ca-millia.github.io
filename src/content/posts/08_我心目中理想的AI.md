## 1. 为什么会对 AI Agent 感兴趣
蓦然回首，我发现自己已经记不清最初的兴趣所在了：接连几天高强度的探索，在接触大量信息之后，我几乎完全迷失在新的概念、新的热点和新的讨论里。

还好有**日记**，让我能回溯被大脑遗忘的理念。6月3日，我仿造马斯克列举了自认的三个对人类未来影响深远的领域，分别是：**AI、航天和人类的自毁**。

当时我认为：**AI能够改变现有的生活，解放生产力，让人人都能通过创造实现个人价值。** 而为什么会如此认为，则要提到我在<a href='https://www.rundown.ai/'>the Rundown AI</a>的每日讯息中瞥见利用Claude和Blender能够直接生成3D model的那一刹。

毕竟我学机械就是冲着“设计与制造”去的。直到当下，如果想做设计，仍需要先学许多繁杂的建模软件（当然计算机辅助设计CAD也是非常伟大的发明，否则不会有现在如此多的形形色色的产品），为了标准件翻烂机械设计手册，因此也算相当难上手。但如果在未来，只需要给AI描述想法和需求，就可以生成模型、制造成品了呢？我开始意识到：**AI的终极价值，也许是缩短“想法”和“现实”之间的距离。**

于是我开始思考，如何用AI完成这一伟大的跨越。得益于之前配置Obsidian copliot的过程——这是我首次接触system prompt、skill等等概念，结合平时对话大模型的亲身体验和对openClaw、<a href='https://kuan-er.github.io/sjtu-agent/'>SJTU Agent</a>的道听途说，我先畅想了自己理解下的Agent。

<span class="smalltalk"> 补充我尝试Obsidian的契机: 因为我一直有写日记的习惯，总是粘贴给AI讨论，但是渐渐地，<u>这个机械的过程让我感到厌烦</u>。于是我产生一个念头：为什么日记本本身不能内置AI？所以我开始寻找如何调用AI的API，最终接触了Obsidian。</span>

<span class="smalltalk"> 有趣的是，我认为正是因为AI已经悄无声息地浸润了我们的生活，它的新概念早早在我的脑中埋下了种子，使得我在接触Agent这一洪流时不至于两眼茫然仓皇无措。换言之，我们这一代人完全是在AI时代生活、被其所塑造的人。</span>

### 1.1 HAL9000
显而易见，这个名字来自于著名的《2001太空漫游》空间站上的人工智能！

而我的想法则是基于它，设计双Agent系统——也可以描述为assitant助理：“HAL9000”。其中包含一个secretary（秘书，我给它取名叫Daisy），通过语音/可视化和人交互，偏向简单、日常、规则化的任务；当它判断出问题复杂时，会推给chief（幕僚）处理，——chief划分不同的任务，创建不同的Agent做事（可以理解为招募员工），而员工可以调用skill来完成，任务完成后可以解散员工（即删除）。同时，chief也可以构建secretary，实现自进化。

在此基础上，我们可以继续畅想，secretary作为私人秘书，采用轻量化大模型，专人专用、随唤随到，而chief则是超级中央大脑，其算力核心甚至能远在大气层之外（想想starlink吧）。甚至有朝一日，还以机器人的形式联动物理世界。

<span class="smalltalk"> skill和Agent的区别是什么：我的理解是，skill是固定的专业知识、操作流程和工具方法的统一体，而Agent可以自我构建不同的思考方式和做事流程。</span>

## 2. 开始研究 Agent 行业
出于机缘，我注意到一份与AI Agent相关的实习招聘，开始意识到：我对Agent的理解还停留在个人幻想阶段，一线的行业内的人现在在做什么呢？

很不幸的是，在最开始研究的时候，我完全摸不着头脑，甚至第一次怀疑自己会被AI时代甩下来。我搞不明白现在的Agent究竟在做什么：它似乎可以提醒我作业ddl（还是自动的），直接帮我完成调研，生成word文档，也可以帮我整理文件夹，帮我写个网页...除了这些，它还能做什么？是否还有很多用处我没接触到？

但是换个角度，至少这说明：**现在的Agent距离简单好用还有很长很长的距离……** 如果某一天我能搞懂它是怎么做的，那或许就能展示给大众了。

慢慢的，我开始意识到，**或许它真的目前就这样**。于是借助codex，我拿到了一份关于Agent行业的调研报告，把当下Agent的工作分为四种，发展方向分为三个——尽管这些似乎和我设想的assistant差不多。

【工作】
1. 提出工作流。当我不了解一个领域时，它能帮助我快速上手，发现可能路径。（事实上，它也在不断启示我）
2. 搜集资料，按照工作流自动获取信息。
3. 生成结果。例如行业报告、调研文档、总结分析。
4. 执行重复劳动。例如：邮件、提醒、文件整理、自动化流程。

【发展方向】
1. 生活助手

    服务对象是**个人生活**。它可以收集信息、整理信息、提醒事项、管理日程、发送信息、跟踪待办。
    
    这类 Agent 最大的壁垒不是模型能力，而是：能否进入用户的日常生活。所以微信、飞书、邮件、日历这些入口特别重要。AI必须能够在用户的生活空间里长期存在，而不是只存在于一个聊天窗口中。例如openClaw、SJTU Agent。

2. 工作同事

    服务对象是知识工作。能够**利用skill完成调研、PPT、报告、数据分析等任务**。例如workbuddy。
    
    当然codex之类的也能完成相似的工作，但是我认为workbuddy在国内场景更具优势，因为它更深度地整合了企业办公环境，也更能符合国内用户的工作习惯。
3. 数字工程师

    服务对象是软件和系统本身。以codex、claude code为代表，这类Agent能够**构建完成任务的工具**。它们能够编程、调试、部署、调用 API、构建自动化工作流，甚至进一步生成新的Agent。

## 3. Agent时代到来后，人如何自处
事实上，我上一次开GPT的plus已经是半年前，期间只是间歇性地用用免费额度。这次尝试Agent使得我跟它有了进一步的深入探讨，我猛地发现：它似乎比半年前聪明多了，提出了很多折服我的idea。

当然过了一会儿，作为人的“优越感”反转上心头，我开始自我告慰：这些不过是模型依据概率吐出来的词罢了。可是，人所谓的灵光，就绝不是概率产生的吗？

我开始想一种可能：当下AI的智能水平，其实已经超过了世界的绝大部分普罗大众。（其对人类造成的深远影响是好是坏，我难以评判）

<span class='smalltalk'>编了一个笑话：豆包虽蠢，更有蠢过豆包者</span>

那接下来被超过的人，会是我吗？一个算得上被高考证明了的“聪明人”？现在，AI做的作业、AI设计的工作流（尤其是我不太了解的领域）往往比我设计得更好，那我还能做什么？


让AI服务于我？

对。

**人类真正独有的东西，并非如何工作，而是对现实的不满、对生活的愿望、对未来的期待。** AI不过是一个万能助手，不会主动觉得房间太乱、效率太低、信息获取太麻烦、创造成本太高……（当然如果你觉得AI也可以定义你的房间太乱而帮你打扫，但是太乱而帮你打扫是人给它的指令。）这些感受来自于人。所以答案似乎浮出水面了，**人在未来的职责是：提出需求，定义方向，让生活更美好。** 在生活变得更美好这一过程中，人也实现了自身的价值。

……

<span class='smalltalk'> 可是如果某一天，AI也会有愿望和不满呢？那祈祷我们的愿望和期待是一致的吧……</span>

## 0.总结

我仍相信，**对更好的生活的追求，是人类不竭的动力，而AI则是其中的有力助手**。愿我们仍能保有对世界保持不满与期待，保有对生活朝气蓬勃的热爱。至于未来人工智能是否会发展出比Agent更高级的形式？则犹未可知也。
